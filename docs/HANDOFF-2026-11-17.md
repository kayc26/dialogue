- **Ask Kay before any production change**: database writes, function deploys, `kb:load`, and pushes (pushes deploy the site). Ask before any live model run too: the budget is $15 (ADR-0012), and `kb:eval-faq --yes` costs about $0.01.
- **`.env.local`** holds the shared OpenRouter key and the owner database URL. Never print or inspect it; scripts read it via `--env-file`.
- **Deploying the function**: run `npx -y neon@latest config plan --branch <branch> --env .env.local` first, then `npx -y neon@latest deploy --branch <branch> --env .env.local --no-env-pull`.
  - Without `--no-env-pull`, the CLI rewrites `DATABASE_URL` in `.env.local`.
  - After a deploy, the old copy can answer for about a minute.
- **Testing the proxy**: use a browser-style preflight (`-X OPTIONS -H "Access-Control-Request-Method: POST" -H "Access-Control-Request-Headers: authorization,content-type,x-title"`). Plain curl skips the preflight.
- **Diagnosing a live reply**: read the latest `public.triage_events`.
  - `detail.calls` lists each model call; `detail.guard` and `detail.blocked_draft` show what the guard blocked; `detail.social` shows which small-talk reply was given.
  - Reply text is in `public.messages`.
- **Reading test runs**: read `kb/out/eval-faq.md` by whole sections, not grep (ADR-0013, iteration 20).
- **ADR tools** count only `answered` as closed.
- **zsh**: an unquoted `$VAR` holding several paths is not split into words; list paths explicitly in `git add` / `git commit --`.
