## Watch for

- **Ask Kay before any production change**: database writes, function deploys, `kb:load`, auth settings, and pushes (pushes deploy the site).
- **Ask before any live model run**: the budget is $15 (ADR-0012). The repeat-run scripts cost under $0.01 each.
- **`.env.local`** holds the shared key and the owner database URL. Never print or inspect it; scripts read it with `--env-file`.
- **Deploying the function**: run `npx -y neon@latest config plan --branch <branch> --env .env.local`, then `npx -y neon@latest deploy --branch <branch> --env .env.local --no-env-pull`. Without `--no-env-pull`, the CLI rewrites `DATABASE_URL` in `.env.local`.
- **Diagnosing a live reply**: read the latest `public.triage_events`. `detail` has `calls`, `guard`, `blocked_draft`, `monitor`, `topics`, `retrieval`, `language` and `social`.
- **The models vary from run to run.** Repeat each case several times before concluding (see `scripts/ephemeral/2026-11-17-monitor-carb-amounts.ts`).
- **zsh** doesn't split an unquoted `$VAR` holding several paths into words, so list paths explicitly in `git add` / `git commit --`.
- **Node** comes from asdf: run `source .claude/agent.env` before `npm` or `npx`.
